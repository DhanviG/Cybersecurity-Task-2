# Task 2 – Web Application Security

## Objective
The objective of this task was to understand and test common web application vulnerabilities in a safe, controlled, and authorized testing environment.

## Overview
This task involved testing a vulnerable web application to understand how common security vulnerabilities can be identified, analyzed, and assessed.

## Activities Performed
* Tested for **Cross-Site Scripting (XSS)**.
* Tested for **SQL Injection**.
* Intercepted and analyzed web requests.
* Examined application responses during testing.
* Studied the security impact of common web vulnerabilities.

## Learning Outcome
This task provided practical exposure to web application security testing and helped in understanding common vulnerabilities, their potential impact, and the importance of secure input validation and handling.

## Disclaimer
All security testing documented in this task was performed within an **authorized and controlled testing environment** for educational and cybersecurity training purposes.
No unauthorized systems or applications were targeted.
